
# 🗂️ Program for cordinating users

Welcome to the repository for the **Program for cordinating users**! 🧾📁
This application offers a straightforward and secure solution for managing users’ documents via an intuitive web interface. It is built as a **QT project** with implemented **CRUD functionalities** (Create, Read, Update, Delete).

## 🔧 Technologies Used:
* **C++** – full-stack
** – for interactive features
* **MySQL** – relational database for storing user and document data
* **XAMPP** – local server package (Apache + MySQL)
* **QT Craetor** – primary code editor used during development
 
## 🧠 Features
The app allows both users and administrators to manage personal documents efficiently. Key features include:
* 🔐 **Add users** 
* ❌ **Delete users** 
* 📋 **Show Ghannt Diagram**

## 🗂️ Database Structure

The database is designed to support:
* Adding users to database
* Deleting users from database
* Showing Ghannt Diagram
